# Véloce 0.2.3

- Fn pendant le chargement affiche « Préchauffe du modèle… », puis « Prêt à dicter ».
- Le message reste visible après avoir relâché Fn. Une fois le modèle prêt, maintenez Fn à nouveau pour parler.
- En mode barre de menus, un court message accompagne le glyphe pendant la préparation.
- Si le chargement échoue, le message indique d’ouvrir Véloce pour réessayer.
